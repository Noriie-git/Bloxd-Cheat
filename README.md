# BloxD.io Cheats Website

A GitHub Pages-ready static website inspired by the provided BloxD.io Cheats screenshot.

## Files

- `index.html` — page structure
- `style.css` — design and responsive layout
- `script.js` — button notification behavior

## Add your real links

Open `index.html` and replace the `href="#"` buttons with your actual URLs.

For example:

```html
<a class="button primary" href="https://example.com/script.user.js">Userscript</a>
```

For Discord:

```html
<a class="button discord" href="https://discord.gg/YOURINVITE">Fallen Client</a>
```

## GitHub Pages

1. Create a GitHub repository.
2. Upload the three website files.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select your main branch and `/ (root)`.
6. Save and wait for GitHub Pages to publish the site.
