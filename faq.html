How do I install these clients?

Download the script files and load them using an extension like Tampermonkey in your browser.

Is it safe to use on my main account?

We highly recommend using alternate accounts when testing or using these clients to prevent any potential bans.

My client is not working, what do I do?

Make sure the game has not updated recently. Join our Discord server for support and updated versions.
